# 05 / Screens and wireframes

**Research date:** 2026-11-24. **Scope:** nine proposed product surfaces. **Evidence / sources:** prior Studio screen/rollout notes and [00](00-RECONCILIATION.md), [navigation](02-INFORMATION-ARCHITECTURE.md). **Verified:** current Studio supports per-job tabs, validation, QA, queue and health; example content below is fixture-only. Not production actions or a visual implementation.

Wireframe notation: `A | B` means columns; `/` separates rows; `→` is a drill-in. Desktop includes global rail; tablet keeps a condensed rail and uses drawers; mobile includes nav trigger, route heading and bottom action when needed. The responsive panes below specify actual reading order. [Tokens](06-VISUAL-DESIGN-SYSTEM.md) · [Interaction rules](07-INTERACTION-DESIGN.md) · [API](08-API-GAP-ANALYSIS.md).

| Surface, goal and action | Data and operation | Load / empty / error / success | Acceptance and keyboard |
|---|---|---|---|
| Mission: unblock highest-priority job; click “Review script” | job list, actionable review subjects, queue and health; no computed ETA | placeholder sections / “Create first draft” / partial-source banner with last read time / selected row opens exact tab | stage links distinguish waiting and failed; Tab through action rows before recents |
| Create: choose feasible plan; edit and validate | spec validation/create, canonical budgets and blocking missing inputs; proposed plan and import | retain editor while verifying / starter input cards / inline field errors + summary / saved job link, no auto-run | typing a topic never starts production; error summary focuses first invalid field, native text editing preserved |
| Batch: review rows before submit | proposed import, row validation, durable submit receipt; queue later | parse progress by rows, not timer / CSV template / invalid rows plus reason / receipt shows submitted, skipped, failed | invalid row cannot block valid selections; select-all offered as explicit page/filter scope; keyboard can inspect/blocker-edit each row |
| Campaign: keep series consistent | revisioned defaults, episodes, assets; proposed fork and diff | skeleton for brief and list / seed episode / missing asset flag is scoped / successful revision shows affected drafts only | r3 never changes ep.01 bound to r2; link to effective values; no drag-only ordering |
| Library: find and export | persisted job and artifact summaries, per-item export preflight | image placeholders with dimensions / clear filters or create / “eligibility unavailable” disables action / exported files and receipt | no guessing readiness from MP4 presence; checkbox and select all state announced; text-size filters wrap |
| Video: understand progress and recover | stage read model, logs, media, QA, rerun preview; no raw path trust | load only changed pane / “not run” / “failed at align” + safe retry / new attempt attached to same job | resume targets exact job; focus stays on selected stage as events arrive; keyboard scroll log without trapping |
| Creative: pick reusable artifact without false readiness | capability registries, rights and asset index; proposed attach/compatibility | skeleton / no compatible items, show all / preview missing keeps tile inspectable / attach into draft, no automatic application | runtime badge and compile status both visible; reduced-motion preview opt-in; use actual asset rights metadata or “unknown” |
| Review: decide against exact revision | current subject and digest, media/preview, explicit grant, proposed history/diffs | load subject before enabling grant / none due / stale or lost connection clears intent / grant receipt links stage | approval confirmation never auto-submits, returns focus to row, new subject forces rereview; video track/transcript alternative when available |
| Operations: diagnose, not invent activity | queue/health/logs, existing requeue and manual CLI; proposed task receipts | independent health and queue refresh / no worker evidence / unavailable distinct from stopped / new attempt plus next state | never display fake agents, live percent or cancel; keyboard-decodable status and copy local remediation command |

**Assumptions:** 390 CSS px minimum design fixture; test 320 px reflow too. **Open questions:** analyst-style multi-column batch editing may need a dedicated tablet editor; test with a 20-row task before committing layout.
