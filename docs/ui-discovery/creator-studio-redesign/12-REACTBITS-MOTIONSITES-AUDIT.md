# 12 / Design ecosystem audit

**Research date:** 2026-11-24. **Scope:** direct site and source inspection, no downloads executed or dependencies installed. **Evidence / sources:** [React Bits site](https://reactbits.dev/), [README and catalogue](https://github.com/DavidHDev/react-bits), [license](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md), [manifest](https://github.com/DavidHDev/react-bits/blob/main/package.json), [SplitText source](https://github.com/DavidHDev/react-bits/blob/main/src/content/TextAnimations/SplitText/SplitText.jsx), [MotionSites](https://motionsites.ai/) and [terms](https://motionsites.ai/terms), [UI UX Pro Max README and license](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill). Public pages and linked repo sources inspected; no interaction or performance profiling.

**Verified findings:** React Bits advertises 215+ React components across text, animation, component, micro-interaction, and backgrounds. JS/TS and CSS/Tailwind select source flavor, not a vanilla runtime; shadcn copying is optional delivery, still React. Full demo package includes GSAP, Motion and Three.js; component dependencies vary. SplitText imports React hooks, GSAP, ScrollTrigger, SplitText and `@gsap/react`. MIT + Commons Clause is not plain MIT: upstream restricts sale, sublicensing and redistribution of components, including bundled and ported versions. Treat repo shipping as a license review question; no copied code recommendation. MotionSites is a prompt and visual inspiration catalogue; its own site loading React does not establish that showcased outputs require it. Terms restrict redistributing prompts/source; do not copy either. No uniform component dependency list or accessibility guarantee verified. UI UX Pro Max is an MIT-licensed design guidance/CLI project, not a shipped UI component runtime. Use its public recommendations as prompts to test, not proof of WCAG conformance or permission to install a skill.

**Assumptions:** no paid assets and no dependency exception in design phase. **Open questions:** confirm license if a future developer proposes exact React Bits reuse; measure a real prototype before adopting any heavier motion.
