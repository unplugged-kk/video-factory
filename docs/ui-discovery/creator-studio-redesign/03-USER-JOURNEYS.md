# 03 / Journeys

**Research date:** 2026-11-24. **Scope:** eight operator workflows. **Evidence / sources:** `contentos/ui/api.js`, `contentos/ui_api.py`, `contentos/videojob.py`; [current capability map](00-RECONCILIATION.md). **Verified:** per-job operations exist; calls marked Proposed do not. `/api/v1` prefix omitted below. Responsibility remains with the operator for writes and grants; agents provide drafts, plans or handoff deliverables only.

| Journey | Screen sequence and operator action | Calls and state changes | Agent, approval and failure/output |
|---|---|---|---|
| A Single | Create → topic → choose format/lang → fill/review script → validate spec → Job → review → export receipt | Proposed plan; `POST /specs/validate`, `/specs`, `/jobs/:id/run`; `GET /jobs/:id`; `POST .../approve` at script then composition; `GET/POST .../export` | Agent may draft sourced script; operator approves each stage explicitly. Incomplete topic stays draft. Missing renderer stops before run; failed QA routes to recovery, not export. Final output is MP4 + receipt. |
| B Independent batch | Batch → import 20 CSV rows → preview mappings → edit languages, workflows and looks row-by-row → filter blockers → submit ready selection → monitor | Proposed import/validate/submit, per-row `POST /specs/validate` semantics; core queue primitives; draft → validated/blocked → submitted per row | No group approvals or implicit agent launch. Duplicate transport retry returns same row receipt; collision is actionable; keep invalid rows editable. A failed Hindi row cannot stall ready English rows. Output: stable batch/row IDs and individual job links. |
| C Campaign | Batch → New series → brief/brand/assets/voice/template → seed 20 episodes → inspect inherited values → override ep 04 → explicitly rebase selected drafts later | Proposed campaign/default revisions and fork/rebase operations; resolved spec saved per episode; newer defaults do not mutate existing jobs | Agent suggests creative direction; operator selects defaults and confirms rebase diff. Rebase of reviewed version is a new draft and new approvals, not change in place. Missing shared assets block only dependent drafts. Output: episodes + immutable config revision references. |
| D Upload | Create → source material → select local media → inspect file/rights/readiness → attach or hand off | Proposed controlled import, inspection and explicit asset linking; current local index is not upload; MPT local path input is lane-specific | No arbitrary filesystem path pass-through. Unsupported media stays unattached with reason; talking-head and lyrics show manual/planned. No private/paid fallback. Output: local asset identity plus supported draft or handoff checklist. |
| E Reference | Create → reference → rights/status → collect authorized observations → build original brief/storyboard → choose a runnable lane or handoff | Proposed reference inspection/task; current sampling/lookup CLI manual, no automatic full analysis; `POST /specs/validate` only once a valid spec exists | Agent can annotate pacing, palette, shot language and evidence timestamps, not copy media. Missing rights prevents inclusion, not local abstract notes. Output: reusable original plan labeled research, with manual Track B preparation where needed. |
| F Review | Review inbox → immutable subject view → inspect script/title, storyboard, exact composition or final media → approve exact current source or request changes | `GET /jobs/:id`, media/preview, `POST .../approve` (`seenDigest`); Proposed sealed subject/revision and history | Storyboard notes and creative verdict are not existing engine gates. Show subject type, digest, revision and diff. Mismatch refreshes subject and clears confirmation. Human grant explicit; never carry over after edit. Final review shows QA provenance and creative review separately. |
| G Recovery | Operations/Job → failure details → log and remedy → check affected stages → retry scoped stage or requeue → observe result | `GET .../stages/:stage/log`, `GET .../rerun?stage=`, `POST .../rerun`, optionally `POST /queue/:id/requeue`; refresh detail after events | Agent may summarize sanitized evidence, not trigger retry. No safe retry shown while lock held; ambiguous response rereads before retry. Cancel UI selection, not running processes. Output: new attempt under same job and prior evidence retained. |
| H Bulk export | Library → select eligible job revisions → preflight each → review target and skipped rows → confirm → inspect receipts | Existing per-job `GET/POST /jobs/:id/export`, proposed bulk receipt and idempotent coordinator; submitted → exported/skipped/failed per item | No batch bypass and no publish. Recheck eligibility at execution. A destination conflict or stale receipt affects only that item. Retry failed only after new preflight; do not automatically force overwrite. |

**Assumptions:** public state comes from backend; no agent fabricated progress. **Open questions:** per-item export conflict resolution and review notes persistence. [Interaction rules](07-INTERACTION-DESIGN.md) · [API gaps](08-API-GAP-ANALYSIS.md).
