# Prompt: Evaluate an upstream video/animation repository

Research the original repository, default branch, README, license, releases, source layout, dependencies, examples, tests, and relevant issues. Do not rely on stars or social posts alone.

Compare each capability with the live Video Factory. Record:
- actual implemented functionality and evidence;
- license and commercial-use restrictions;
- runtime, model, API, and paid-service requirements;
- compatibility with the current renderer and agent setup;
- overlap and maintenance cost;
- security risks and any code that must not be executed;
- adopt/adapt/reference/defer/reject recommendation;
- smallest safe experiment and acceptance criteria.

Do not install or execute upstream code during the audit. Treat repositories as untrusted. Produce a source-linked report and a proposed integration diff, but wait for approval before implementing or adding dependencies.
