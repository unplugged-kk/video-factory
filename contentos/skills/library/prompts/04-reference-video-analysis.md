# Prompt: Analyze a reference video and adapt techniques

Analyze the supplied URL or file only to the extent access permits. Never claim to have watched unavailable media.

Extract:
- hook and narrative structure;
- scene-by-scene timeline;
- shot scale and composition;
- motion, camera language, transitions, pacing;
- typography, diagrams, overlays, texture, color, sound design;
- how visuals reinforce each spoken idea;
- techniques reusable as general design principles;
- original elements that should not be copied directly.

Deliver `reference-analysis.md`, a timestamped storyboard, a style card, and a list of reusable techniques. Use original assets and scripts; do not reproduce copyrighted characters, exact frames, or a creator's distinctive sequence shot-for-shot. Map techniques to existing factory capabilities and identify what is missing. Do not install tools or render until the user approves the proposed adaptation.
