# Prompt: Generate the publishing package

Use only the approved final render and verified episode metadata.

Generate:
- 3 title options;
- description appropriate to the platform and audience;
- relevant hashtags/tags;
- thumbnail concept and image prompt or existing thumbnail asset;
- chapter/timestamp suggestions where appropriate;
- credits and asset attribution;
- a pre-publish checklist;
- a short rationale for the recommended title and thumbnail.

Do not invent facts, claim credentials, add unsupported performance promises, or use copyrighted imagery without rights. Keep publishing approval separate from package creation. Do not upload or publish unless explicitly authorized and the configured publishing gate is satisfied.
